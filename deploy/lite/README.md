# 薅乐马轻量版

同一 Release、同一源码提交的现成前端 + 必要 Node 适配器，无独立管理、注册或充值后台。

1. 校验 Release 中 `oh-haolema-lite.sha256` 后解压 `.tar.gz`。
2. 将 `.env.example` 复制为 `.env`；设置 `USAGE_SOURCE=sub2api` 或 `newapi`，填写对应网关地址和服务端只读管理员凭据。
3. `docker compose up -d --build`，打开 `http://127.0.0.1:8098/`。不需要安装前端开发环境。

没有网关配置也可试玩，榜单明确显示未连接。上游恢复后可刷新榜单。个人账号沿用网关会话：同域集成使用主站既有登录；独立域名仅凭部署管理员 Token 不会让访客自动成为该账号。

积分桥是可选扩展；未配置时不生成替代积分。试玩不发放账户奖励，真实抽奖和余额兑换保持关闭。管理员凭据只进入 API 容器，不放在浏览器、URL 或 runtime-config。

需要公网访问时通过既有 HTTPS 反向代理转发本地 8098。更新时替换解压内容，保留私有 `.env` 并重新 `docker compose up -d --build`。

我们自己的 Sub 使用原生排行榜/积分和内嵌前端，因此只固定本仓库前端源码，无需另外运行此适配器。
