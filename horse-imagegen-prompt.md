# Pixel Horse Pet Image Generation Prompt

Use case: game asset / digital pet spritesheet
Asset type: SUB2API token leaderboard animated mascot

Create a compact pixel-art digital pet horse mascot for a token usage leaderboard. The horse should feel like a tiny desktop companion pet: chibi proportions, readable silhouette, chunky 1-2 px dark outline, stepped pixel edges, limited palette, flat cel shading, tiny limbs, expressive face.

Character identity:
- Small chestnut horse with cream muzzle and black mane.
- Friendly, slightly overworked office-worker personality.
- No logo, no text, no watermark.
- Transparent-ready subject on perfectly flat solid #00ff00 chroma-key background.
- Do not use #00ff00 in the subject.
- No cast shadow, no floor, no scenery, no gradients in the background.

Spritesheet layout:
- 3 rows x 4 columns.
- Each frame centered with generous padding.
- Same horse identity in every frame.
- Row 1: working. Horse sitting at a tiny laptop/computer, typing, focused eyes, small keyboard movement.
- Row 2: idle/fishing. Horse slouching or leaning back, holding a tiny fishing rod or snack, playful "slacking off" pose.
- Row 3: sleep. Horse dozing at the workstation, eyes closed, small attached Z-shaped sleep mark only if it touches/overlaps the horse silhouette.

Style constraints:
- Pixel-art-adjacent, not painterly, not realistic, not 3D.
- Crisp hard edges, no soft blur, no glow, no loose particles.
- Props must be attached or very close to the horse, not floating separately.
- Avoid detailed background, UI panels, speech bubbles, readable text, farm elements, barns, crops, hay fields, windmills.

Composition:
- Front 3/4 view, tiny desktop mascot scale.
- The horse should be recognizable at 64px and charming at 128px.
- Use warm browns, cream muzzle, black mane, small blue laptop, tiny red accent.
